# Apex.World

Non-destructive world generator for the S&box engine.
Very early WIP project started on 05/08/2026.

## Current Features

- Terrain & Texture Generation
- Localized texture spawners with bounds
- Layer stack system with per-layer outputs
- Non-destructive generation workflow
- Detail Spawning
- Rule-based detail spawning system
-Terrain-aware placement
- Rotation, scaling, density and filtering controls
- Mask-driven spawning
- Spawn zones and bounds support
- GPU Clutter Rendering
- Chunked GPU-instanced clutter renderer
- Frustum-cullable chunk bounds
- Editor + runtime compatible
- Runtime reconstruction without respawning
- Large-scale foliage rendering support
- Minimal GameObject overhead
- Editor preview generation
- Non-destructive spawning workflow
